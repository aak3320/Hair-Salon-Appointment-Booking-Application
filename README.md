# Hair-Salon-Appointment-Booking-Application
This website helps users find salons that suit their budget, users can book  appointment and pay for service easily. And allows users to find salons according to their  requirements based on user reviews and ratings.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Materialize CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **External API:** Yelp API

---

## Prerequisites

Make sure you have the following installed:

- Node.js 
- MongoDB 
- npm

---

## Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/aak3320/Hair-Salon-Appointment-Booking-Application.git
```
### 2. Install all required dependencies
```bash
npm install
```
### 3. Run the application
```bash
node server.js
```
### 4. Open in browser
http://localhost:3000
